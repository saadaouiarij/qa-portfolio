# Tests d'API REST avec Postman

Collection de 7 requêtes (GET, POST, PUT, DELETE) sur l'API publique
JSONPlaceholder (https://jsonplaceholder.typicode.com), avec des vérifications
automatiques : code de statut, structure de la réponse, valeurs, temps de réponse.

## Utilisation
1. Importer `collection-postman-jsonplaceholder.json` dans Postman.
2. Lancer la collection avec le Collection Runner.
